# RICOCHET DUEL v2

## 起動
Node.js 18以上でプロジェクト内から `npm install` → `npm start`。`http://localhost:3000` を開きます。

## GitHub / Render
ZIPを展開してGitHubの新規リポジトリへアップロード。Renderで **New + → Web Service** を選択し、リポジトリを接続します。
- Runtime: `Node`
- Build Command: `npm install`
- Start Command: `npm start`

## v2追加機能
- オーナーのみ開始・終了・ポイントリセット
- 試合開始前/終了後のみ設定変更
- 弾速、加速ON/OFFと倍率、時間/ラウンド数、開始弾数、増殖方法・倍率・指数増殖、弾サイズ
- アクセントカラー・背景色変更
- 得点時のカラフルなバースト、失点時の暗いフラッシュ
- 太い単線の外周、壁反射時の位置補正
- 初回はオーナー側から発射。得点後は失点した側が次を発射
- バーの移動速度を発射時/反射時の弾の縦方向速度へ反映

## 補足
- ラウンド数はどちらかが得点した回数です。時間制は指定分数経過で終了します。
- 増殖は各ボールが最初にバーへ当たったときに発生し、同時弾数は最大24個です。
- ルーム情報はメモリ上にあり、サーバー再起動で消えます。公開運用では再接続、ルーム期限、レート制限、永続DB等の追加を推奨します。
