# NEON PONG ONLINE

Pongベースのリアルタイム1対1オンライン対戦（弾の増殖あり）。Node.js + Express + Socket.IO。

## ローカルで起動
```
npm install
npm start        # http://localhost:3000
npm test         # ゲーム計算の単体テスト
```
同じネットワークの別端末からは `http://<このPCのIP>:3000` で遊べます。

## オンライン公開（Render）
1. このフォルダをGitHubにアップロード
2. Render で「New → Web Service」→ リポジトリを選択
3. Build Command: `npm install` / Start Command: `npm start`（Nodeは18以上）
4. 発行されたURLを相手に共有。無料プランは一定時間アクセスがないと停止し、再開に少し時間がかかります。
※ サーバーは1台構成です（複数台に増やすとルームが共有されません）。

## 遊び方
1. 名前を入れて「ルームを作成」→ 表示された5文字のIDを相手に伝える（相手はIDで「参加」）
2. ロビーで設定。弾・増殖・バー・試合の設定は**オーナーのみ**変更可（相手は閲覧のみ）。「プレイヤー」タブで各自が背景色・アクセントカラー・バー形状・名前を変更
3. オーナーが「ゲーム開始」。各ラウンドは、発射側のバー先端に弾が表示され、**発射側のプレイヤーがクリック/タップ/スペースを押すと発射**されます（待機中もバーは動かせます）
4. 操作: マウス / タッチ（画面内を上下） / W S ↑ ↓
5. 試合中、オーナーは画面下の「試合を終了」で途中終了できます（現在の今回得点で勝敗を判定、同点は引き分け）
6. 試合終了後は設定を変えて「再開」できます（得点は保持。「得点リセット」で0に戻せます）

## ルールと設計上の判断
- 発射: 初回はオーナー側から。以降は失点した側から（再開後も維持）。発射側がクリックするまで待機し、弾はその側のバーから出ます。初期の弾が複数ある場合も1個ずつ順番にバーから出現
- 得点: 弾が相手側の端を通過すると1点（弾ごとに加点）。全ての弾が消えると次のラウンド
- 増殖: バーに当たるたびに発動。通常=毎回+N個、指数的=その時の弾数×N個を追加。弾は設定した間隔で1個ずつ出現。処理負荷対策で同時存在数は内部上限150個（設定の上限ではなく、ブラウザ停止防止の安全装置）
- 弾速・加速度に設定上の上限なし。衝突は「次に当たる瞬間」を計算する連続衝突判定のため、極端な速度でもすり抜けません（1フレームあたり最大64回の出来事を処理）
- 制限時間は弾の発射後のみ減少。ラウンド制の目標は「再開後の今回の得点」で判定
- 背景色: 自分の画面は自分の背景色、相手の色は相手のバー・得点・演出に反映（公平性のため）
- バー形状は見た目のみ。当たり判定は全形状共通の長方形（公平性のため）
- 演出は「強/弱/なし」を試合画面で切替可能（光過敏への配慮）
- 切断: 試合は一時停止し、同じブラウザで再接続すると復帰。10分誰も戻らないとルームは削除
