# RICOCHET DUEL

リアルタイム通信で遊ぶ、1対1のオンライン・ボールはじき返しゲームです。

## ゲーム内容
- ルーム作成で4文字のルームコードを発行
- 相手がコードを入力すると対戦開始
- 左右のパドルを操作して、中央のボールを相手側へ打ち返す
- 相手側の端を越えると得点
- マウス、タッチ、上下矢印キーに対応
- Node.js + Express + Socket.IO

## ローカル起動
Node.js 18以上をインストールして、プロジェクトフォルダで実行します。

```bash
npm install
npm start
```

ブラウザで `http://localhost:3000` を開きます。
同じPCで試す場合は別タブを開き、別のプレイヤーとしてルームコードに参加してください。

## GitHub と Render への公開

1. このZIPを展開します。
2. 展開したファイルをGitHubの新しいリポジトリにアップロードします。
3. Renderにログインし、**New + → Web Service** を選びます。
4. GitHubリポジトリを接続します。
5. 次のように設定します。
   - Runtime: `Node`
   - Build Command: `npm install`
   - Start Command: `npm start`
6. 無料枠など利用プランの条件を確認してDeployします。
7. Renderが発行したURLを開き、2つのブラウザ/端末で対戦をテストします。

## 注意
- RenderではWebSocket接続を許可するWeb Serviceとして公開してください。
- 無料インスタンスは一定時間アクセスがないとスリープする場合があります。最初の接続に時間がかかることがあります。
- 現在は簡易版です。ルーム情報はサーバーのメモリ上にあり、サーバー再起動で消えます。
- 公開運用する場合は、通信頻度制限、切断時の再接続、ルーム有効期限、勝敗確定処理などの追加を推奨します。
