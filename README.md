# NEON PONG ONLINE（サーバー + ブラウザ版）

Pongベースのリアルタイム1対1オンライン対戦（弾の増殖あり）。Node.js + Express + Socket.IO + ws。
このフォルダは **ブラウザ版そのもの** であり、**Unity版（unityroom公開）が接続するサーバー** でもあります。

- ブラウザ版: Socket.IO（`public/`）
- Unity版: 素のWebSocket（`wss://<ホスト>/ws`、電文は `イベント名|JSON`）。同じルーム管理を共有するため、ブラウザ版とUnity版は同じルームで対戦できます。

## ローカルで起動
```
npm install
npm start        # http://localhost:3000   （Unity版は ws://localhost:3000/ws）
npm test         # ゲーム計算とルーム管理の単体テスト
```

## オンライン公開（Render）
1. このフォルダの中身をGitHubのリポジトリにアップロード（ブラウザの「Add file → Upload files」で可。Gitコマンドは不要）
2. Render で「New → Web Service」→ リポジトリを選択
3. Build Command: `npm install` / Start Command: `npm start`（Node 18以上）
4. 発行された `https://xxxx.onrender.com` が公開URL。Unity版には `wss://xxxx.onrender.com/ws` を設定
   - 無料プランは一定時間アクセスがないと停止し、次の接続で起動に1分ほどかかります
   - サーバーは1台構成のみ（複数台に増やすとルームが共有されません）

## 遊び方・ルール
1. 名前を入れて「ルームを作成」→ 5文字のルームIDを相手に伝える（相手はIDで「参加」）
2. ロビーで設定。弾・増殖・バー・試合の設定は**オーナーのみ**変更可。「プレイヤー」タブで各自が背景色・アクセントカラー・バー形状・名前を変更
3. オーナーが「ゲーム開始」。各ラウンドは、発射側のバー先端に弾が表示され、**発射側のプレイヤーがクリック/タップ/スペースを押すと発射**されます（待機中もバーは動かせます）
4. 操作: マウス（画面のどこでも追従）/ タッチ / W S ↑ ↓。試合中はオーナーが「試合を終了」、全員が「退室」できます
5. 試合終了後は設定を変えて「再開」できます（得点は保持。「得点リセット」は確認つき）

- 発射: 初回はオーナー側、以降は失点した側（再開後も維持）。初期の弾が複数でも1個ずつ順番に出現
- 得点: 弾が相手側の端を通過すると1点（弾ごとに加点）。全ての弾が消えると次のラウンド
- 増殖: バーに当たるたびに発動（前面・側面・背面すべて）。通常=毎回+N個、指数的=その時の弾数×N個を追加。同時存在数は内部上限150個（ブラウザ停止防止の安全装置。弾速・加速度の設定値には上限なし）
- 衝突: 連続衝突判定のため極端な速度でもすり抜けません。バーが急に動いて弾を飛び越えた場合も弾を跳ね返します
- 制限時間は発射後のみ減少。ラウンド制の目標は「再開後の今回の得点」で判定
- バー形状は見た目のみ。当たり判定は全形状共通の長方形（公平性のため）
- 切断: 試合は一時停止し、同じブラウザ/端末で再接続すると復帰。10分誰も戻らないとルームは削除
